# rapp-specs — the global specs brain

Every protocol of the ecosystem, in one clone, as a verifiable brain: rapp/1 (the
envelope), dogg/0 (the network), rapp-brain/0 (knowledge as dimensions), cast/0
(films), skill-jacket/0 (verifiable skills), and the dogg SKILL. Each spec's home repo
stays canonical; a daily sync mirrors the texts here and `brainify --dogg` mints a
`brain.page` frame per change — so "what did spec X say at tick N" is answerable
forever, across ALL specs at once, and any AI can call the whole canon down in one
pull (or offline from any mirror).

Verify: `python3 tools/verify_thread.py`. Read a spec: `specs/`. The chain: `brain/`.
